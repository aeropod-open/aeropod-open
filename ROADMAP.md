# AeroPod Open Roadmap

AeroPod Open is being developed as an open-source AI + IoT precision-farming platform for education, research and sustainable urban agriculture.

This roadmap outlines the early direction of the project. It will evolve as the community grows and contributors help shape AeroPod Open.

## Phase 0 — Community Formation

**Current phase**

Our immediate goal is to establish the foundation for a healthy open-source project and community.

- [x] Create the AeroPod Open GitHub organization
- [x] Create the main AeroPod Open repository
- [x] Create the initial project README
- [x] Enable GitHub Discussions
- [x] Create the Welcome discussion
- [x] Create the first community Ideas discussion
- [ ] Form the founding contributor group
- [ ] Define the initial open-source scope
- [ ] Define project governance
- [ ] Select the appropriate open-source licence
- [ ] Create contribution guidelines
- [ ] Create a Code of Conduct

## Phase 1 — Open Architecture

The next stage will define how AeroPod Open should work technically.

- [ ] Publish a high-level AeroPod Open architecture
- [ ] Define the open API structure
- [ ] Define sensor data formats
- [ ] Define hardware and software boundaries
- [ ] Define third-party integration methods
- [ ] Document communication between IoT devices, APIs and applications
- [ ] Define which AeroPod components remain commercial services

Potential open interfaces may include:

- pH
- EC
- water temperature
- water level
- environmental sensors
- lighting
- water usage
- crop data
- automation controls

Develop AeroPod Open as a practical platform for education and research.

- [ ] Create student project guides

Our longer-term goal is to develop an ecosystem around open precision-farming technology.

- [ ] Support third-party hardware

- [ ] Establish contributor recognition
- [ ] Develop a community showcase
- [ ] Encourage research publications using AeroPod Open
- [ ] Collaborate with other open-source communities
- [ ] Organise community workshops or hackathons

## Open Platform and Commercial Services

AeroPod Open is intended to provide an open technology and developer ecosystem.

AeroGreen Asia may separately provide commercial products and services such as:

- Certified AeroPod hardware
- Installation and deployment
- Managed cloud services
- AI services
- Maintenance and technical support
- Multi-site management
- Education programmes
- Training
- ESG and sustainability reporting
- Enterprise integrations

The exact boundary between open-source components and commercial services is currently being defined.

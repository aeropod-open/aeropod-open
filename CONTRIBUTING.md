# Contributing to AeroPod Open

Thank you for your interest in contributing to AeroPod Open.

AeroPod Open welcomes contributions from developers, students, educators, researchers, growers and open-source enthusiasts.

You do not need to be a programmer to contribute.

## Ways You Can Contribute

You can help through:

- Ideas and discussions
- Software development
- IoT and embedded development
- Sensor integrations
- AI and data-analysis experiments
- Documentation
- Tutorials
- Testing
- UI/UX design
- Hydroponics experiments
- Student projects
- Research projects
- Translation
- Community support

## Before You Start Coding

If you have a new idea or feature proposal, please start with a GitHub Discussion.

This gives the community a chance to discuss the idea before significant development work begins.

Once an idea becomes actionable, it may be converted into a GitHub Issue.

## Contribution Workflow

A typical contribution may follow this process:

1. Join or start a GitHub Discussion
2. Agree on the problem or idea
3. Create or select an Issue
4. Develop the contribution
5. Submit a Pull Request
6. Review and discuss the changes
7. Merge the contribution

## Good First Contributions

New contributors are encouraged to start with small tasks such as:

- Improving documentation
- Creating tutorials
- Adding sensor examples
- Testing APIs
- Creating ESP32 / Arduino examples
- Improving UI/UX
- Fixing small bugs
- Adding example datasets

As the project develops, we will label suitable tasks with:

`good first issue`

and

`help wanted`

## Student Contributions

Students are especially welcome to participate.

Possible student projects may include:

- Automatic water refill systems
- Water consumption monitoring
- LED lighting control
- Environmental sensing
- ESP32 integrations
- Computer vision for plant monitoring
- AI crop-data analysis
- Mobile applications
- Data visualisation
- Hydroponics experiments

## Documentation

Good documentation is an important contribution.

Contributors can help improve:

- Setup guides
- API documentation
- Tutorials
- Diagrams
- Examples
- Troubleshooting guides
- Student learning materials

## Community Behaviour

We want AeroPod Open to be a welcoming, respectful and constructive community.

Please follow the project's Code of Conduct when participating.

## Questions?

If you are unsure where to start, open a GitHub Discussion under Q&A.

🌱 Thank you for helping build AeroPod Open.

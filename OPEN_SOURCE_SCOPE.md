# AeroPod Open — Initial Open-Source Scope

This document defines the initial proposed boundary between AeroPod Open community components and AeroGreen commercial components.

The scope is expected to evolve based on technical review, business requirements and community feedback.

## Proposed Open Components

The following components are being considered for open-source release:

- Public API specifications
- Sensor data formats
- ESP32 and Arduino examples
- Sensor integration libraries
- Sample API clients
- Example dashboards
- Developer documentation
- Student project examples
- Sample datasets
- Third-party hardware integration examples
- Basic automation examples
- Community-developed modules

## Components Under Review

The following components require further review before a decision is made:

- Mobile application source code
- Core backend services
- Device provisioning software
- Automation engine
- AI models and AI workflows
- Database schemas
- Device management tools
- Cloud infrastructure components

These may be released fully, partially, or kept commercial depending on security, intellectual property and business considerations.

## Commercial Components

AeroGreen Asia may continue to provide commercial products and services separately from AeroPod Open, including:

- AeroPod certified hardware
- Installation and commissioning
- Managed cloud hosting
- Managed AI services
- Fleet and multi-site management
- Maintenance and technical support
- Education programmes
- Training
- ESG and sustainability reporting
- Enterprise integrations
- Custom development
- Commercial support agreements

## Security and Privacy

The following must never be published in an open repository:

- Passwords
- API keys
- Database credentials
- Device credentials
- Customer information
- Personal data
- Production configuration secrets
- Private certificates or encryption keys

All code must be reviewed before public release.

## Intellectual Property Review

Before publishing software, we should confirm that AeroGreen has the right to release it.

Special review may be required for:

- Third-party libraries
- Contractor-developed software
- University collaboration work
- Jointly developed intellectual property
- Proprietary datasets
- Licensed AI models

## Community Feedback

This scope is not final.

We welcome feedback from developers, students, researchers, educators and open-source contributors through GitHub Discussions.
